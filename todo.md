Currently we're using the word Conversation in an ambiguous way. It could mean (1) what happens in a single @chat function, (2) a single LLM round trip, (3) what happens in a single @workflow function (which may call other @chat or @workflow functions) (4) what happens in an invocation of the CLI from the moment of the call to the moment the CLI exits. Speculate on some better domain-specific vocabulary that we could use for these different things. Currently "chat" is a word we're using to distinguish the smallest unit of LLM conversation that returns a valid Pydantic object, and "workflow" to talk about an arbitrary composition of "chat" and "workflow" functions. This would allow us to be more precise when talking about different levels of the system.
